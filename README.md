\# HealthConnect Norway



A healthcare interoperability portfolio project that simulates patient information exchange between a hospital system and a municipal healthcare system, using HL7 FHIR.





\## Why I built this



I have worked in the healthcare sector and have seen first-hand how important it is that patient information flows safely between hospitals and municipal services. This project combines that domain experience with backend development and HL7 FHIR.





\##Status



In progress, following a 12-week learning roadmap.



\-\[x] M1: C# fundamentals and Patient model

\-\[ ] M2: First working Patient API (ASP.NET Core)

\-\[ ] M5: First FHIR resources

\-\[ ] M12: Portfolio-ready release v1.0





\## Planned tech stack



C#, ASP.NET Core Web API, Entity Framework Core, PostgreSQL, HL7 FHIR R4 (Firefly .NET SDK), Docker and GitHub Actions.

\## Disclaimer



This is a learning and portfolio project. It uses \*\*synthetic data only\*\* and is not certified, production-connected, or integrated with Norsk helsenett, HelseID, or any real healthcare system.
